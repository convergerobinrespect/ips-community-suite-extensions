## 🚀 Quick Setup

Installing these extensions is incredibly simple. You can either upload the XML files directly through your Admin Control Panel or use our automated deployment script.

```bash
# Clone the repository
git clone https://github.com/your-username/ips-community-suite-extensions.git

# Navigate into the directory
cd ips-community-suite-extensions

# Option 1: Use the automated deployment script (requires FTP/SSH)
./deploy.sh --host your-site.com --user admin --pass secret

# Option 2: Upload the XML files manually via ACP
# Go to AdminCP -> System -> Applications & Modules -> Upload New Application
```

Once installed, navigate to the Plugins menu in your Admin Control Panel. You will find a new section dedicated to the IPS Extensions suite where you can configure each module, toggle features on or off, and customize the settings to perfectly match your community's unique brand.

## 🧠 Under The Hood: How It Works

Building on top of Invision Community requires a deep understanding of its underlying architecture. Our extensions leverage the built-in `ContentRouter`, `Member`, and `Dispatcher` classes to hook into the core system without modifying the original source files. This means you can safely update your IPS core without fear of losing your custom modifications.

The UI themes included in this repository are built using SCSS and modern JavaScript (ES6+). We utilize the native `ips.ui` framework to ensure that all animations, modals, and dropdowns function flawlessly across all devices. The themes are also designed with accessibility in mind, meeting WCAG 2.1 AA standards for contrast and screen-reader compatibility.

One of the standout extensions is the **Monetization Module**. It includes a highly optimized checkout flow for premium subscriptions, complete with localized currency support, automatic invoice generation, and seamless webhook integration with Stripe and PayPal. For forum administrators looking to monetize their content, this module can be a game-changer.
